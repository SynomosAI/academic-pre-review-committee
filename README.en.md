## What this skill covers

A multi-reviewer pre-screening committee simulating journal submission review, with five reviewer roles:

1. **Theory contribution reviewer**: does the paper offer a new theoretical lens / conceptual framework
2. **Methodology reviewer**: rigor, reproducibility, data soundness
3. **Literature dialogue reviewer**: effective engagement with existing literature, clear positioning
4. **Logic chain reviewer**: argument coherence, premise-conclusion consistency, no leaps
5. **Editor pre-screen**: overall fit, desk-reject decision

Each reviewer scores independently; results are aggregated into a pre-screen conclusion.
